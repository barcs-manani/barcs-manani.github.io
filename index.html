about

An engineer who moved into software — and kept the rigor.

I'm a full-stack software developer currently involved in testing the upcoming e-commerce platform BuyersBounties, where I validate user flows, report on application behaviour and identified bugs, among others. Previously, I was part of the team behind Tripzoori, an online travel booking platform, where I developed and maintained production-ready software using React on the frontend and Python FastAPI on the backend, designed PostgreSQL database models, built APIs, and contributed to deploying and maintaining the platform in production.

My background is a B.Sc. in Electrical & Electronics Engineering, not Computer Science—and I've found that to be an advantage rather than a detour. Engineering taught me to approach problems systematically, reason about complex systems, and design with reliability in mind. That same mindset shapes how I build software: viewing applications as interconnected systems with real-world constraints, performance considerations, and failure modes—not simply collections of features.

Beyond day-to-day development, I'm committed to continually expanding my expertise. I'm currently deepening my knowledge of large-scale software architecture, modern backend design, cloud deployment, and cybersecurity while building practical, scalable solutions across the web development stack.
